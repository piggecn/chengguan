# 社区城管日常巡查记录平台

移动端优先 · 免登录 · Docker 单容器部署。

## 快速启动

```bash
docker compose up -d --build
```

浏览器打开 `http://<NAS地址>:8080`。

## 使用流程

1. 首次打开选「姓名 + 4 位密码」（人员名单见 `app.py` 里的 `PERSONNEL`，按实际人员修改后重建镜像）。
2. 首页点「+」新增巡查记录：选中队、填小区、选分类、写描述、拍照上传。
3. 待处理记录进详情页点「整改销号」：写处理结果、拍整改后照片，前后对比留痕。
4. 首页顶部「案件登记」登记执法案件，列表里直接改进度、改罚款金额。
5. 「统计」页看按中队 / 分类 / 人员 / 小区的统计与案件汇总。

## 关键特性

- **离线可记**：弱网提交失败自动暂存手机本地（含照片），首页「N 条待上传」一键补传。
- **原图保留**：照片不缩分辨率、不压画质，仅 HEIC 转 JPEG（质量 95），后期汇报材料可直接用；列表用 200px 缩略图。
- **可选密码门**：环境变量 `ACCESS_PASSWORD` 不设则免登录；设了则打开站点先输密码。

## 配置项

| 环境变量 | 说明 |
|---|---|
| `ACCESS_PASSWORD` | 可选。站点级访问密码，留空免登录 |
| `SECRET_KEY` | 会话签名密钥，正式使用务必修改 |
| `DATA_DIR` / `UPLOADS_DIR` | 数据与照片目录，Docker 内已默认挂载 |

## 本地开发

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python app.py   # 开发模式，http://127.0.0.1:5000
```
