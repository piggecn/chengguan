# 社区城管巡查记录平台

面向社区城管中队的移动端巡查记录系统：手机上随手拍照上报问题、跟踪整改销号，一台 NAS 即可部署。

## 主要功能

- **巡查记录**：选中队 → 选小区（自动补全）→ 点选问题分类（12 类：牛皮癣小广告、乱堆放杂物、电动车乱停放、流动摊贩、出店经营、毁坏绿化等）→ 写描述 → 拍照上传（可多张、原图保留）；待处理 → 整改销号，现场照与整改照前后对比留痕
- **账号权限**：主管理员 / 办公室管理员 / 中队长 / 副中队长 / 队员五级角色。登录页「选单位 → 选姓名 → 输 4 位密码」；主管理员、办公室、中队长可建号（办公室和中队长只能建副中队长与队员），建号自动生成随机 4 位密码；中队长/副中队长看本中队全部，队员只看自己，办公室/主管理员看全部
- **居民投诉**：登记居民投诉（小区/电话/内容/照片），一键标记已处理并记录处理人
- **案件登记**：执法案件登记，列表内直接改进度（调查中 → 已立案 → 已办结）、改罚款金额
- **数据统计**：按中队 / 问题分类 / 小区排行 / 案件汇总，支持按月切换，每项都能点进去看明细
- **导出**：一键下载 ZIP——Excel（汇总表 + 每个问题分类一张表）+ 照片按分类分文件夹（原图，材料可用）
- **离线可记**：弱网提交失败自动暂存手机本地（含照片），网络恢复一键补传
- **PWA**：浏览器「添加到主屏幕」后像 App 一样全屏使用，登录状态常记 180 天

## NAS 部署

```bash
# 1. 把本项目拷到 NAS 上，例如 /volume1/docker/chengguan
cd /volume1/docker/chengguan
# 2. 一键构建并启动
docker compose up -d --build
```

- 访问地址：`http://NAS的IP:8755`（手机在同一局域网直接用浏览器打开）
- 数据都在 `data/`（数据库）和 `uploads/`（照片）两个目录，换容器、升级镜像数据不丢，**备份拷这两个目录即可**
- 容器异常自动重启（restart: unless-stopped）

## 升级

```bash
cd /volume1/docker/chengguan
git pull
docker compose up -d --build
```

或直接用 Docker Hub 现成镜像：

```bash
docker run -d --name chengguan \
  -p 8755:5000 \
  -v /volume1/docker/chengguan/data:/app/data \
  -v /volume1/docker/chengguan/uploads:/app/uploads \
  --restart unless-stopped \
  piggecn/chengguan:latest
```

## 配置项

| 环境变量 | 说明 |
|---|---|
| `ACCESS_PASSWORD` | 可选。留空免登录；设置后打开站点先输这个密码（防外人访问） |
| `SECRET_KEY` | 会话签名密钥，正式使用改成随机长字符串 |

## 首次使用

1. 打开站点 → 单位选「大队」→ 选「主管理员」→ 密码 `0000` 登录，到「账号管理」（右上角齿轮）改密码
2. 在「账号管理」给各中队建账号（自动生成 4 位密码，转交本人）
3. 队员手机浏览器打开站点 → 「添加到主屏幕」，即可像 App 一样随手使用
